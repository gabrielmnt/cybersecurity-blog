# Cybersecurity Blog

A personal space dedicated to exploring, learning, and sharing knowledge about cybersecurity.

This blog is where I document things I discover, experiment with different technologies, and put my knowledge into practice. Through projects, research, technical explanations, and hands-on experiences, I aim to better understand the different aspects of cybersecurity while sharing what I learn along the way.

My goal is to turn curiosity into practical knowledge, document my progress, and explore topics that interest me in the field. If something I share ends up helping someone else understand a concept, solve a problem, or discover something new, that's even better.

## About the Blog

Cybersecurity is a broad field with plenty of things to explore. This blog reflects that variety, covering different topics and experiences rather than focusing on a single area.

Some of the content you may find here includes:

- **Hands-on Projects:** Practical labs, experiments, and cybersecurity projects.
- **Security Concepts:** Explanations of networking protocols, technologies, tools, and fundamental concepts.
- **Vulnerabilities & Exploits:** Exploring vulnerabilities, understanding how they work, and examining their security implications.
- **Security Incidents:** Research and analysis of data breaches, attacks, and real-world security events.
- **Tools & Experiments:** Testing security tools, exploring technologies, and documenting practical findings.
- **Learning Notes:** Interesting discoveries, technical explanations, and lessons learned throughout my journey.

## Technologies

The blog is built using:

- **Jekyll** – Static site generator.
- **Ruby** – Environment and dependency management.
- **HTML & CSS** – Structure and visual presentation.
- **Markdown** – Content and technical documentation.
- **GitHub Actions** – Automated build and deployment.
- **GitHub Pages** – Website hosting.

## Repository Structure

```text
├── .github/
│   └── workflows/
│       └── deploy.yml
├── _layouts/          # Page and post layouts
├── _posts/            # Blog articles
├── assets/
│   ├── css/            # Stylesheets
│   └── Images/         # Screenshots and diagrams
├── _config.yml         # Jekyll configuration
├── index.html          # Homepage
├── posts.html          # Posts page
├── Gemfile             # Ruby dependencies
└── README.md
```

## Deployment

The blog uses GitHub Actions to automatically build and deploy the website through GitHub Pages.

Whenever changes are pushed to the `main` branch, the configured workflow builds the Jekyll site and publishes the updated version.

## A Note About This Blog

This blog is part of my ongoing journey in cybersecurity. Not every post represents an advanced project or an in-depth technical analysis. Sometimes, it is simply about exploring something new, testing an idea, or explaining a concept that I found interesting.

The intention is to keep learning, experimenting, and sharing knowledge along the way.

**Discover, experiment, learn, and share.**
